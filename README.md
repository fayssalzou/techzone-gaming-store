# TechZone — متجر تجريبي مع لوحة تحكم

نسخة أولية قابلة للتشغيل محلياً: متجر عربي، سلة مشتريات، إنشاء طلبات محفوظة في SQLite، ولوحة إدارة محمية لتحديث حالة الطلبات وإضافة/تعديل/حذف المنتجات.

## المتطلبات
- Node.js 20 أو أحدث
- اتصال إنترنت أول مرة لتنزيل المكتبات (`npm install`)

## التشغيل على Windows
1. فك ضغط ملف المشروع.
2. ثبّت Node.js من الموقع الرسمي إذا لم يكن مثبتاً.
3. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
4. عدّل `SESSION_SECRET` إلى قيمة طويلة وعشوائية، وعدّل `ADMIN_PASSWORD` إلى كلمة مرور قوية.
5. افتح Terminal / PowerShell داخل مجلد المشروع ثم نفّذ:
   ```bash
   npm install
   npm start
   ```
6. افتح `http://localhost:3000` للمتجر.
7. افتح `http://localhost:3000/admin` للوحة الإدارة وسجّل الدخول ببيانات `.env`.

## ما الذي توفره؟
- المنتجات والأسعار محفوظة في قاعدة SQLite محلية.
- الطلبات تُحفظ في قاعدة البيانات وتظهر في لوحة الإدارة.
- حالات الطلب: جديد، قيد المعالجة، تم الشحن، مكتمل، ملغى.
- إدارة المنتجات: إضافة، تعديل، حذف.
- كلمة مرور الإدارة لا تُخزّن كنص داخل الكود؛ تُقرأ من `.env`.
- حماية أساسية عبر جلسة آمنة وHelmet وتحديد محاولات تسجيل الدخول.

## مهم قبل النشر الحقيقي
هذه نسخة MVP تعليمية وليست منصة تجارة جاهزة للإنتاج. قبل فتحها للعامة:
- استخدم HTTPS، `SESSION_SECRET` قوياً، وكلمة مرور فريدة.
- اضبط `NODE_ENV=production` خلف استضافة تدعم HTTPS.
- أضف نسخاً احتياطية لملف قاعدة البيانات ومراقبة للخادم.
- لا تجمع بيانات أكثر مما تحتاج، وضع سياسة خصوصية وشروط بيع واضحة.
- راجع سياسات الدفع والتوصيل والضرائب المناسبة لنشاطك.
- لا توجد بوابة دفع إلكترونية في هذه النسخة؛ الطلبات تُسجّل فقط.
- قاعدة البيانات محلية في `data/techzone.sqlite`؛ لا تحذفها إن أردت الاحتفاظ بالطلبات.

## الاستضافة
يمكن نشره على خادم Node.js يدعم تطبيقات Express وملفات SQLite الدائمة. لا تستخدم استضافة ملفات ثابتة فقط مثل GitHub Pages لتشغيل الخادم. تأكد أن منصة الاستضافة توفر تخزيناً دائماً، لأن القرص المؤقت قد يمسح الطلبات عند إعادة التشغيل.
